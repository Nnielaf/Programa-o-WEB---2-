1. Comentários

Sintaxe: <!-- comentário -->, em uma ou várias linhas
Não aparece no navegador do usuário

2. Iframe

<iframe> (inline frame): uma "janelinha" que mostra outra página dentro da sua
Uso comum: incorporar mapa do Google (pelo Maps: copiar HTML e colar, já vem o iframe pronto)
Atributos: src (URL da página), width e height (em pixels)
O conteúdo pode ser de qualquer servidor, desde que o dono libere o acesso

3. Listas

Ordenada <ol>: itens numerados
Atributo type: 1 (números), a/A (letras minúsculas/maiúsculas), i/I (romanos minúsculos/maiúsculos)
Não ordenada <ul>: itens com marcador
type: disc (padrão), square, circle
Itens <li>: usados em <ol> e <ul>, com abertura e fechamento
De definição <dl>: pares de <dt> (termo) e <dd> (definição)
Pode ter dois termos para a mesma definição, ou duas definições para o mesmo termo
Aninhada: uma lista dentro de um <li>, e o </li> só fecha depois da lista interna
O navegador recua a lista interna e costuma mudar o marcador

4. Links com <a>

<a href="URL">texto clicável</a>
URL absoluta: endereço completo (http://www.imdb.com), usada para outros sites
URL relativa: caminho em relação à página atual, usada no mesmo site
Mesma pasta: só o nome do arquivo (reviews.html)
Pasta filha: movies/cinema/listings.html
Subir um nível: ../index.html
Subir dois níveis: ../../index.html
A partir da raiz: /index.html (o / é o diretório raiz)
A página principal do site (e de cada pasta) se chama index.html
Para links dentro do próprio site, prefira URL relativa
E-mail: href="mailto:jon@example.org" abre o programa de e-mail com a mensagem endereçada
target: _self (mesma aba, padrão), _blank (nova aba ou janela), _parent (frame pai)
Âncora na mesma página: dê um id ao destino (<h2 id="arc_shot">) e use href="#arc_shot" (o # seguido do id)
Para outra página: pagina.html#id

5. Dica do VS Code: Emmet

Plugin que gera HTML e CSS a partir de abreviações
html:5 + TAB gera a estrutura completa do HTML5
ul>li*5 + TAB gera uma lista com 5 itens (> aninha, *5 repete)

6. Elementos de bloco e inline

Bloco: sempre começam em nova linha (<h1>, <p>, <ul>, <li>)
Inline: continuam na mesma linha dos vizinhos (<a>, <b>, <em>, <img>)

7. Atributos id e class

id: identifica um elemento de forma única na página
Pode ser usado em qualquer elemento, mas não pode repetir na mesma página
Deve começar com letra ou sublinhado (não número)
No CSS: p#pullquote { ... }
class: marca vários elementos com o mesmo grupo
Vários elementos podem ter o mesmo valor
Um elemento pode ter mais de uma classe (class="importante entrada")
No CSS: .importante { ... }

8. Agrupamento com <div> e <span>

<div>: contêiner de bloco, começa em nova linha e agrupa elementos (cabeçalho, comentários, seções)
<span>: equivalente inline do div, para um trecho de texto sem outro elemento adequado
Com id ou class, o CSS controla o espaço ocupado e a aparência do conteúdo
Comentário <!-- fim do header --> ajuda a marcar onde o <div> termina
